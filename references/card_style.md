# 圖卡設定文件

圖卡目前實際使用的配色、字型、字級與圖形設定。色值已與品牌規範 v5.3 YAML 核對（2026-10-28）。程式讀取的版本是 `app/brand.json`，修改時兩邊一起改。

token 欄寫「待補」的，是 v5.3 的名稱尚未提供；`pn-chart-2`～`pn-chart-6` 依 `pn-chart-1` 的命名推定，待核對。

## 一、畫布與版面

| 項目 | 設定 |
|---|---|
| 尺寸 | 1080 × 1350（4:5） |
| 安全邊 | 四邊 64px |
| 背景 | #FFFFFF（token 待補），只用淺底 |
| 頁首 | 左：「代號 · 季度 · 圖名」；右：@pathfindernote。頁首下 12px 畫一條 1px 強線 |
| 頁首線到內容的距離 | 中間圖卡 32px；封面與 K1 48px |
| 頁尾 | 1px 弱線，線上方留 48px、線下方留 12px；線下是「資料來源＋免責」合併成一段，署名在最後一行右側 |
| 頁尾文字 | 有資料來源時：「資料來源：…。（計算註明）僅供資訊分享，不構成投資建議。」計算註明寫法為「（項目）依損益表科目計算」，不寫主詞 |
| 圓角／陰影／外框 | 一律沒有 |

### 用色規則

- **結果項才用正負色。** 漲藍（pn-up）／跌橘（pn-down）只用在結果項：利潤（毛利、營業利益、淨利）、虧損、業外損益。損益流向圖的利潤節點與流向帶依數值判斷：≥ 0 用 pn-up，< 0 用 pn-down。
- **扣減項一律灰。** 成本、費用、資本支出、股東回饋等扣減項，一律用 pn-chart-other，不因負值改用跌橘。
- **漲跌只上色箭頭。** ▲▼ 用漲跌色，後面的數字一律用主文字色（pn-text-1）。
- **流向帶透明度。** 流向帶用節點顏色的 30% 透明度。
- **同業圖。** 本公司長條用 pn-text-1，其他公司用 pn-chart-other。

## 六、數字格式

| 項目 | 設定 |
|---|---|
| 千分位 | 加逗號 |
| 小數位（經換算或計算的數字） | 金額 2 位、百分比 1 位、倍數 1 位、百分點 1 位。例如營收由百萬換算成 B、年增率、利潤率 |
| 小數位（原文直接抽取、未經換算的數字） | 依抽取值的位數，不套用固定位數、不在產圖階段四捨五入；同一項目內的數字用相同位數，以位數最多的為準，不足補 0。目前用於 A1 的 EPS（本季與去年同期為同一項目）、A1 採用公司公布的 EPS 年增率（例如 ▲ 49%）、K1 的財測與財測調整（同一列為同一項目；需要換算單位的金額除外） |
| 漲跌幅 | 「▲ 5.2%」：符號在前、空一格、不加 +／− |
| 年增率標示 | 依序判斷，符合第一個即採用：① 去年同期＝0 →「N/M」② 去年同期＞0、本期≥0 → 百分比與 ▲▼ ③ 去年同期＞0、本期＜0 →「轉負」④ 去年同期＜0、本期＞0 →「轉正」⑤ 去年同期＜0、本期≤0 →「N/M」。四捨五入後為 0.0% 時顯示 0.0%、不加 ▲▼。「轉正／轉負／N/M」用中性灰色（弱字 #5F6B7D），不用漲跌色、不加 ▲▼。不以分母取絕對值的方式計算負基期的百分比。利潤率變化一律用 pp，不受此規則影響 |
| 百分點 | 「▲ 2.2 pp」 |
| 一般負值 | 「−0.84」（U+2212），不加括號 |
| 金額單位 | 美股 B（十億）、台股 億；貨幣寫 USD／TWD，放在「單位：」或欄名 |
| 季度 | 2026Q3（公司財年換算成日曆季度） |
| 日期 | 2026-10-20 |

## 七、各張圖卡的固定文字

| 圖卡 | 頁首圖名 | 其他文字 |
|---|---|---|
| A1 封面 | 財報快報 | 代號、「公司｜季度 財報」、「營收 USD X B，年增 X%」、三個 KPI（營收、營益率、EPS；EPS 標籤依口徑顯示「稀釋 EPS」或「基本 EPS」，美股稀釋、台股基本），各附「去年同期」與年增或年變動 |
| C 損益流向 | 損益流向 | 單位、節點名稱與數值、利潤率 |
| B 營收拆解 | 營收組成／各地區營收 | 單位、圖例、期間、柱頂總額（財報公布的淨額）、右側「名稱 金額 ▲ 年增」。調節項目（營收表中列在各部門小計之外、但計入總營收的項目）不畫進柱子、不列入圖例，兩期都放頁尾註腳「{期間} 總營收 {總額} 含 {項目名} {金額}」。一般部門出現負值時畫在 0 軸下方。同一項目兩期用同一種處理方式。柱內各段加總＋註腳項目須等於柱頂總額（容許四捨五入誤差，工具自動檢查） |
| D 利潤率 | 利潤率 | 單位、圖例、兩端數值、右端「▲ X pp」 |
| G 現金流量 | 現金流量與股東回饋 | 單位、圖例（小計／支出）、「股東回饋」分組名稱 |
| K1 下季財測／財測調整 | 下季財測（只有財測調整時為「財測調整」） | 標題「公司下季財測（季度）」或「公司財測調整（FY 年度）」；財測表頭「項目／財測」；財測調整表頭「項目／前次財測／本次財測」（不用「調整前／調整後」，避免和 Adjusted 指標混淆；原文有前次財測發布日期時寫「前次財測（M/D）」），本次財測前加 ▲（上修，pn-up）或 ▼（下修，pn-down）。財測調整表的數字欄寬固定（每欄至少 280px，數字更長時才加寬）並靠右；項目欄為其餘寬度，名稱過長時自動換行，「（單位）」不拆開沒有財測也沒有財測調整時不產出 K1 |

## 八、標籤文字

- 所有圖卡標籤一律中文。科目名稱依序採用：公司設定檔 → 原文本身是中文 → 科目對照表（`references/labels_zh.json`）→ AI 譯名（台灣常用的財報用語，核對第三層確認）。不直接印英文原文。
- 公司名稱、股票代號、EPS、USD 等代號照原樣。
