# 圖卡設定文件

圖卡目前實際使用的配色、字型、字級與圖形設定。色值已與品牌規範 v5.3 YAML 核對（2026-10-28）。程式讀取的版本是 `app/brand.json`，修改時兩邊一起改。

token 欄寫「待補」的，是 v5.3 的名稱尚未提供；`pn-chart-2`～`pn-chart-6` 依 `pn-chart-1` 的命名推定，待核對。

## 一、畫布與版面

| 項目 | 設定 |
|---|---|
| 尺寸 | 1080 × 1350（4:5） |
| 安全邊 | 四邊 64px |
| 背景 | #FFFFFF（token 待補），只用淺底 |
| 頁首 | 左：「代號 · 季度 · 圖名」；右：@pathfindernote。頁首下 12px 畫一條 1px 強線 |
| 頁首線到內容的距離 | 中間圖卡 32px；封面與 K1 48px |
| 頁尾 | 1px 弱線，線上方留 48px、線下方留 12px；線下是「資料來源＋免責」合併成一段，署名在最後一行右側 |
| 頁尾文字 | 有資料來源時：「資料來源：…。（計算註明）僅供資訊分享，不構成投資建議。」計算註明寫法為「（項目）依損益表科目計算」，不寫主詞 |
| 圓角／陰影／外框 | 一律沒有 |

### 用色規則

- **結果項才用正負色。** 漲藍（pn-up）／跌橘（pn-down）只用在結果項：利潤（毛利、營業利益、淨利）、虧損、業外損益。損益流向圖的利潤節點與流向帶依數值判斷：≥ 0 用 pn-up，< 0 用 pn-down。
- **扣減項一律灰。** 成本、費用、資本支出、股東回饋等扣減項，一律用 pn-chart-other，不因負值改用跌橘。
- **漲跌只上色箭頭。** ▲▼ 用漲跌色，後面的數字一律用主文字色（pn-text-1）。
- **流向帶透明度。** 流向帶用節點顏色的 30% 透明度。
- **同業圖。** 本公司長條用 pn-text-1，其他公司用 pn-chart-other。

## 五、線條與圖形

| 項目 | 設定 |

| 資料線（折線） | 2px，圓角接頭 |

| 圖例與標籤方塊 | 8×8px 正方形、圓角 0，與文字垂直置中；方塊到文字 12px |
| 折線端點 | 圓點，半徑 6px |
| 對比預期的實際值 | 圓點，半徑 10px |
| 流向圖節點寬度 | 14px |
| 長條寬度 | 堆疊長條最寬 96px（有右側標籤時 160px）；瀑布圖最寬 100px；同業橫條最高 48px |
| 表格內距 | 上下 12px、左右 16px |
| 圖例項目間距 | 24px |

## 六、數字格式

| 項目 | 設定 |
|---|---|
| 千分位 | 加逗號 |
| 小數位 | 金額 2 位、百分比 1 位、倍數 1 位、百分點 1 位 |
| 漲跌幅 | 「▲ 5.2%」：符號在前、空一格、不加 +／− |
| 百分點 | 「▲ 2.2 pp」 |
| 一般負值 | 「−0.84」（U+2212），不加括號 |
| 金額單位 | 美股 B（十億）、台股 億；貨幣寫 USD／TWD，放在「單位：」或欄名 |
| 季度 | 2026Q3（公司財年換算成日曆季度） |
| 日期 | 2026-10-20 |
