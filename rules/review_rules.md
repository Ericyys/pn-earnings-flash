# 人工核對：哪些錯誤可以直接改、哪些必須請 AI 重抽

判斷標準只有一個：**這個錯誤是「一個數字或標籤錯了」，還是「AI 讀錯了地方」？**

- 一個數字或標籤錯了 → 錯誤範圍明確，人照原文改正即可，自動檢查會立刻重算驗證。
- AI 讀錯了地方（抓錯期間、抓錯整張表、漏抽整段）→ 錯誤範圍不明，看得到的錯只是一部分，必須請 AI 重新抽取。

所有直接修改都會保留「AI 原值 → 修改值 → 備註」，寫進本季存檔。

## 第一層｜基本設定

| 欄位 | 處理方式 | 原因 |
|---|---|---|
| 公司、代號、幣別、會計準則 | **直接改** | 只是標籤，不影響數字 |
| 金額單位、股數單位 | **直接改** | 數字是照抄原文，改單位只改變換算。改完看「圖卡上營收顯示為」是否合理 |
| 會計期間（FY 季度） | **直接改** | 標籤；只要期末日正確，數字就是對的那一期 |
| 期末日 | **工具自動判斷** | 改完會比對本季數字的出處欄名。欄名是同一期 → 只是標籤寫錯，直接改；不是同一期 → AI 抓錯整欄，**必須重抽** |
| 整份文件是別家公司或別一季 | **重新開始** | 從步驟 1 重做 |

## 第二層｜數字

| 情況 | 處理方式 |
|---|---|
| 個別數字抄錯、正負號錯 | **直接改**：輸入原文數值（括號或 − 都可以） |
| 個別數字抓錯欄或抓到累計數，原文有正確的單季欄 | **直接改**：輸入正確欄的數值，期間類型與出處欄名一併改 |
| 原文根本沒有這個數字 | **清空** |
| 「新增回購授權」其實是剩餘額度 | **移除這一項** |
| 直接修改累計 5 個以上 | 工具會**提醒改請 AI 重抽**：錯這麼多通常是整欄或整張表讀錯，其他沒發現的數字也可能有問題 |
| AI 漏抽整個項目（例如整組地區營收、整段財測） | **請 AI 補抽**：工具不能新增項目 |

改過的數字要重新打勾；自動檢查立刻重算，人工輸入錯誤一樣會被勾稽抓到。

## 第三層｜判斷

第三層的內容（不通過、需確認、PN 計算、AI 疑慮、A／B 差異）每家公司都不一樣，所以**不提供針對內容的固定選項**。每一項：

1. **寫下你的判斷**（必填，存進本季存檔）
2. **選擇結果**，三種結果對所有公司都一樣：

| 結果 | 什麼時候選 | 之後 |
|---|---|---|
| 數據正確，不需要修改 | 原文就是如此（例如公司以括號表示所得稅、原文確實沒有毛利列） | 判斷寫理由 |
| 我已在第一／二層改正 | 錯誤範圍明確，自己照原文改好了 | 判斷寫改了什麼 |
| 交給 AI 修正 | 工具改不了：漏抽、整欄抓錯期間、要改抓欄位或單位、自己找不出錯在哪 | 判斷寫給 AI 的要求，原文送出 |

### 自己改，還是交給 AI？

| 情況 | 建議 |
|---|---|
| 不通過，而且找得到是哪一個數字錯 | 自己在第二層改，改完這項自動消失 |
| 不通過，找不出原因，或很多項同時不通過 | 交給 AI |
| 一兩個數字抓錯欄 | 自己改（連同期間類型、出處欄名） |
| 整欄、整張表抓錯，或期末日不對 | 交給 AI |
| AI 漏抽整個項目 | 交給 AI 補抽 |
| A／B 不同，B 對 | 按「把 A 改成 B 的值」 |
| 原文有毛利等列但 AI 沒抽 | 第二層下方「AI 未填的欄位」補填，或交給 AI |

### 不在每次核對時決定的事

計算方法（EPS 年增率用「淨利 ÷ 稀釋股數」、哪些數字可以由 PN 計算）寫在 `rules/derivations.json`，對所有公司一律適用，確保每張圖卡的算法一致。核對時若認為某家公司不適用，寫在判斷裡，事後由維護者決定是否修改規則。

財測金額單位屬於數據，列在第二層核對，錯了直接改。

## 防呆：修改權不會讓整組圖卡不一致

所有圖卡每次都從**同一份修改後的數據**重新計算，不會有「改了一個數字、其他圖卡還用舊數字」的情況。剩下的風險是「改錯」，由以下機制擋住：

| 風險 | 怎麼擋 |
|---|---|
| 改了一個數字，和其他數字對不起來 | 勾稽檢查立刻重算，出現「不通過」 |
| 輸入時用了不同單位（例如照抄成 B 而不是仟元） | 與 AI 原值差 3 倍以上要按兩次「儲存」，差約 1,000 倍時直接提示單位；正負號相反也要再確認 |
| 金額單位整批改錯 | 用三個獨立數字交叉驗證：EPS（淨利 ÷ 股數）、內文寫的營收金額（例如「$12.9B」）、下季財測營收 |
| 會計期間改錯 | 與期末日比對 |
| 期末日改錯 | 與數字出處的欄名比對，不一致就擋下 |
| 採用 B 的值時，B 用了不同單位 | 差 3 倍以上或 B 的單位不同就不允許一鍵採用 |
| 對「不通過」選「數據正確」硬過 | 工具會自動少畫有矛盾的那一段（例如流向圖只畫到營業利益、不做營收拆解卡），並在第四步列出；**不會畫出與數字互相矛盾的圖** |
| 選「已改正」但其實沒改對 | 檢查仍不通過時，這項不算處理完 |

改過的數字一律要重新打勾，所有修改（AI 原值、修改值、備註）與覆寫理由都寫進本季存檔，事後可以追查。

## 請 AI 修正的流程

工具本身沒有 AI，所以文字要求（例如「請補抽第 5 頁的地區營收」）無法直接執行，會整理成一段**修正要求**：

1. 任何一項選了「交給 AI 修正」或在「其他要求」寫了內容 → 出現修正要求，暫時不能產出圖卡。
2. 複製修正要求，貼回**原本那個 AI 對話**（不要開新對話，AI 才看得到原文與上一版輸出）。修正要求會一併列出你已直接修改的值，要求 AI 照用。
3. 把 AI 重新輸出的 JSON 貼到步驟 1 的 A 欄，按「檢查」。
4. 工具會沿用上一輪的紀錄：數值沒變的勾選保留；你的修改若 AI 已照改就不再重複套用，AI 沒改就繼續套用；AI 改動過的數字取消勾選，需要重新核對。
