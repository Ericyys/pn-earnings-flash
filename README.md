# PN 財報快報｜出圖工具

財報公布後，把公司公布的數字做成 3–5 張 1080×1350 圖卡（Threads／IG／FB 共用）。只呈現公司公布的數據，不下判斷。

三個階段，各管各的：

| 階段 | 做什麼 | 規則 |
|---|---|---|
| 抽取 | AI 把財報上重要的數據盡量全部抽出來（每家公司同一套指令），只照抄、附出處，不做繪圖判斷 | `prompts/`、`schema/` |
| 核對 | 人確認原始數字無誤（第一、二層）；第三層處理數據問題。各公司算式不同時（例如 EPS 的分子），在「公司規範」設定這家公司的算式，存起來下次自動套用，不必改程式 | `rules/review_rules.md`、`rules/company_rules.md` |
| 出圖 | 選圖規則自動決定做哪幾張；資料不完整的圖卡不出。產出前對照新聞稿核對圖卡數字（四捨五入自動通過、定義不同自動加附註、對不上必須修正） | `rules/triggers.json`、`rules/review_rules.md` |

**出圖工具網址**：`https://ericyys.github.io/pn-earnings-flash/`（會自動進入 `app/index.html`）

## 使用流程

| 步驟 | 在哪裡 | 做什麼 | 產出 |
|---|---|---|---|
| 1 | 公司投資人關係網站 | 下載財報新聞稿 PDF | PDF |
| 2 | 出圖工具 | 點頁面上的「美股抽取指令」「資料規格」下載（有更新時重新下載） | 2 個檔案 |
| 3 | AI（新對話、關閉網路搜尋） | 上傳 PDF 與資料規格，貼上抽取指令，複製 AI 回覆的 JSON。新公司前 2 次另用第二個 AI 再抽一次 | JSON |
| 4 | 出圖工具・步驟 1–2 | 選公司、貼上 JSON（A 必填，B 選填），按「檢查」 | 自動檢查結果 |
| 5 | 出圖工具・步驟 3 | 第一、二層對照 PDF 逐項打勾，錯了直接修改；第三層工具會自動分類，你只處理「需要你判斷」 | — |
| 6 | AI（同一個對話） | 第三層有「交給 AI」的項目時，複製工具整理好的文字貼回 AI，再把新的 JSON 貼回步驟 1 按「檢查」（同一問題最多交給 AI 一次） | 新 JSON |
| 7 | 出圖工具・步驟 3 | 「公司規範」：確認 AI 翻譯的科目名稱；這家公司算法不同時選公司算式（第三層也會直接建議）。有調整時按「下載公司規範」，上傳到 `history/<市場>/<代號>/company_rules.json`，下次自動套用 | 公司規範 |
| 8 | 出圖工具・步驟 4 | 按「下一步：核對圖卡數字」。工具列出圖卡上的重點數字並預填新聞稿數字；補空白、處理被標記的行（定義不同會自動加附註，對不上必須回步驟 3 修正） | — |
| 9 | 出圖工具・步驟 5 | 按「產出圖卡」（張數由選圖規則決定，資料不完整的不出），再按「下載全部 PNG」與「下載本季存檔」，存檔上傳到 `history/<市場>/<代號>/`。頁尾放不下的附註會列出來，請寫進貼文 | 2–5 張 PNG、核對紀錄 |

核對規則（哪些錯可以直接改、哪些要交給 AI）：`rules/review_rules.md`
公司規範（各公司可以設定哪些算式）：`rules/company_rules.md`

## 資料夾

| 資料夾 | 內容 | 誰用 |
|---|---|---|
| `app/` | 出圖工具：頁面（`index.html`、`main.js`、`app.css`）、公司規範畫面（`company_panel.js`）、品牌設定（`brand.json`）、計算與核對（`lib/`；公司規範的格式與預設值在 `lib/company_rules.js`）、圖卡底稿（`templates/`）、底稿預覽（`demo/`） | 打開網址時瀏覽器執行 |
| `prompts/` | AI 抽取指令 | 使用者下載後貼給 AI |
| `schema/` | 資料規格：AI 交出的 JSON 必須符合的格式 | 上傳給 AI；工具用來檢查格式 |
| `profiles/` | 美股／台股設定：單位、科目對照、檢查規則 | 工具自動讀取 |
| `rules/` | 選圖規則（`triggers.json`）、可計算數字與各公司可選的算法（`derivations.json`）、核對規則（`review_rules.md`）、公司規範說明（`company_rules.md`） | 工具自動讀取；維護者修改 |
| `references/` | 科目中文名稱（`labels_zh.json`）、圖卡設定文件（`card_style.md`） | 工具自動讀取；維護者參考 |
| `companies/` | 個別公司設定（中文名稱、地區名稱、財年） | 工具讀取；沒有設定檔也能出圖 |
| `history/` | 各公司的規範（`company_rules.json`，工具自動讀取）與每季的核對存檔 | 每次出圖後上傳 |

## 維護

- **新增追蹤公司**：複製 `companies/_template.json` 成 `companies/<市場>/<代號>.json` 填好，再到 `companies/index.json` 加一行，公司才會出現在選單。
- **某家公司的算式不同**：不用改程式，在出圖工具的「公司規範」設定，下載 `company_rules.json` 上傳到 `history/<市場>/<代號>/`。需要新的算式選項時才改程式（`lib/company_rules.js`、`lib/compute.js`、`rules/derivations.json`）。
- **新增科目譯名**：在公司規範確認過的譯名會記在該公司的規範；很多公司共用的科目，再加進 `references/labels_zh.json`，所有公司都不必確認。
- **調整選圖門檻**：改 `rules/triggers.json`，不用改程式。
- **調整圖卡樣式**：改 `app/brand.json`，同步更新 `references/card_style.md`；改完打開 `app/demo/preview.html` 檢查所有底稿。
- **更新檔案**：在 GitHub 按 Add file → Upload files，同名檔案會覆蓋。上傳後等 1–2 分鐘；若畫面還是舊的，按 Ctrl＋Shift＋R（Mac：⌘＋Shift＋R）強制重新整理。頁首會顯示目前版本。
- **改了資料規格**（`schema/`）：抽取指令要同步改，否則 AI 交出的 JSON 會過不了格式檢查。

## 目前的限制

- 台股抽取指令尚未建立（`profiles/tw.json` 已備好）。
- E 卡（對比預期）、F 卡（營運指標）、I 卡（同業對比）的選圖規則與底稿都已完成，但圖卡資料尚未接上：觸發時工具會列出，但不產圖、也不佔張數。目前會產出的條件圖卡是 B（營收拆解）、D（利潤率）、G（現金流量與股東回饋）。
- 工具會讀回 `history/` 的公司規範，但還不會讀回本季存檔，所以利潤率卡只有去年同期與本季兩點。
- 損益流向圖改畫瀑布圖時（虧損），不標佔營收百分比。
- 毛利、營業利益或淨利 ≤ 0 時，損益流向圖會自動改為瀑布圖。
- K1 只在公司有下季財測，或文件明確寫出財測調整（前次財測、本次財測都有數字）時產出；兩者都沒有就不出 K1。
- EPS 年增率：公司有寫、且與公布的 EPS 一致時用公司的數字（例如 +49%），沒有才用公布的 EPS 計算（規則見 `rules/derivations.json`）。所以 A1 上 EPS 年增的位數可能與營收年增不同（例如 ▲ 49% 與 ▲ 11.8%）。
