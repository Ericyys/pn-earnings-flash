# 測試 A｜AI 抽取可行性（Netflix）

## 這次測試要回答的問題

1. AI 能不能依規格，從真實財報抽出格式正確的數據？
2. 抽錯的數字，人工核對抓不抓得到？
3. 人工核對實際要花多久？
4. 兩個不同 AI 的結果差多少？（新公司前 2 次要雙重抽取，這次一起驗證這條規則值不值得）

> 用 Netflix 的原因：它的損益表結構（營業成本、各項營業費用）和 Alphabet 接近，而且會給下季財測，能一次測到最多模組。檔名中的 `NFLX` 換成其他公司代號即可沿用本流程。

全程照 Ryan 未來的真實流程做：**另開新對話、使用一般 AI 介面、只靠上傳的文件。** 測試中不要回到 PN 專案對話求助；卡住的地方直接記在紀錄表，那就是要修的地方。

## 通過標準

| 項目 | 通過條件 |
|---|---|
| 格式 | 兩份 JSON 都能通過格式檢查（測完由 PN 專案對話代跑） |

| 時間 | 不設門檻，只記錄（準確優先於 1 小時） |

## 事前準備（約 5 分鐘）

- [ ] 計時工具（手機碼錶即可），每一步開始與結束都記時間
- [ ] 兩個 AI 帳號：Claude 和 ChatGPT（都要能上傳 PDF）
- [ ] 從 PN 專案對話下載的兩個檔案：`fact_sheet.schema.json`、`extract_us.md`
- [ ] 本檔案（邊做邊填下方紀錄表）

## 步驟 1｜取得財報文件（⏱ 記時間）

1. 到 Netflix 投資人關係網站 ir.netflix.net
2. 找最新一季的財報（Quarterly Earnings 區）
3. 下載**股東信（Letter to Shareholders）PDF**。Netflix 的財報新聞稿就是這份股東信，損益表等財務報表附在最後幾頁
4. 其他檔案（訪談影片、逐字稿）這次不用
5. 檔名改成 `NFLX_<季度>_pr.pdf`，例如 `NFLX_2026Q3_pr.pdf`
6. 在紀錄表填：季度、公布日期、PDF 頁數

## 步驟 2｜第一個 AI 抽取：Claude（⏱ 記時間）

1. 開一個**全新**的 Claude 對話（不要在 PN 專案裡開）
2. 如果介面有網路搜尋開關，**先關閉**（避免 AI 從網路抓到其他數字）
3. 上傳兩個檔案：`NFLX_<季度>_pr.pdf`、`fact_sheet.schema.json`
4. 打開 `extract_us.md`，從「你是財報數據抽取員」那一行開始，**整段複製貼上**後送出
5. AI 回覆中斷或說內容太長 → 輸入「繼續」，直到 JSON 結束
6. 把 JSON 程式碼區塊的內容（`{` 到最後的 `}`）複製到純文字編輯器（Windows 記事本或 Mac 文字編輯的純文字模式），存成 `NFLX_<季度>_A_claude.json`
7. 在紀錄表填：模型名稱、花費時間、輸入「繼續」幾次、AI 有沒有說明任何狀況

## 步驟 3｜第二個 AI 抽取：ChatGPT（⏱ 記時間）

1. 開一個全新的 ChatGPT 對話，同樣先關閉網路搜尋
2. 上傳同樣兩個檔案
3. 貼上同一份指令，**在最後另起一行加上**：`run_id 填 "B"`
4. 存成 `NFLX_<季度>_B_chatgpt.json`
5. 在紀錄表填同樣的項目

## 步驟 4｜人工核對：只核對 Claude 那份（⏱ 記時間）

這一步模擬 Ryan 未來在網頁上做的人工核對。打開 PDF 和 `NFLX_<季度>_A_claude.json`，依下面三層順序核對，結果填進紀錄表的核對表。

**核對方法**：在 JSON 找到該欄位 → 看它的 `row_label` 和 `column_label`（或 `quote`）→ 在 PDF 按 Ctrl+F（Mac 是 ⌘F）搜尋列名 → 確認那一列、那一欄的數字和 JSON 一致。

**第一層：基本設定（6 項，全部核對）**
公司名稱、`fiscal_period`、`period_end`、`monetary_unit`、`currency`、`accounting_basis`

**第二層：會印在圖卡上的數字（全部核對，本季與去年同期都要）**
- `income_statement`：`revenue`、`operating_expenses_total`、`operating_income`、`net_income`、`eps_diluted`
- `operating_expense_items`：每一列
- `segments`：每一項
- `kpis`：每一項的本季數字

**第三層：檢查 AI 自己提出的疑慮**
- `ambiguities` 裡每一條，判斷 AI 說得對不對，記下來

**ChatGPT 那份不用人工核對**，交回後由 PN 專案對話比對兩份差異，看看雙重抽取能多抓到什麼。

## 步驟 5｜交回 PN 專案對話

把以下檔案上傳到 PN 專案對話：
- `NFLX_<季度>_pr.pdf`
- `NFLX_<季度>_A_claude.json`
- `NFLX_<季度>_B_chatgpt.json`
- 填好的本檔案

PN 專案對話會扮演「未來的網頁」：跑格式檢查、勾稽檢查、兩份比對，再跟你的人工核對結果交叉對照，產出測試報告。
