# 完整流程重跑指南（用 Netflix 2026Q3，預計 60–90 分鐘）

目的：用 Ryan 之後會用的同一套工具，從頭到尾自己跑一次。跑完後把遇到的問題記下來，連同待確認事項一起交給 Ryan。

## 0｜更新 GitHub（5 分鐘）

1. 解壓 `pn-earnings-flash-v0.8.zip`，把資料夾**裡面的內容**整批上傳到 repo（Add file → Upload files，同名檔案會覆蓋），Commit。
2. 等 1–2 分鐘，打開出圖工具：
   `https://ericyys.github.io/pn-earnings-flash/app/index.html`
3. 看到「PN 財報快報｜出圖工具」與步驟 1 就代表更新成功。

## 1｜下載抽取指令與規格（2 分鐘）

在出圖工具步驟 1 的說明文字中，點「美股抽取指令」與「資料規格」兩個連結下載。這兩份已更新為 v0.2／1.1，**不要用舊版**。

## 2｜AI 抽取（20 分鐘）

**Claude（A）**
1. 開全新對話，關閉網路搜尋。
2. 上傳 `NFLX_2026Q3_pr.pdf` 與 `fact_sheet.schema.json`。
3. 打開 `extract_us.md`，從「你是財報數據抽取員」開始整段貼上送出。
4. 中斷就輸入「繼續」。完成後複製整段 JSON（有沒有 ```json 框都可以）。

**ChatGPT（B）**：同樣流程，指令最後另起一行加上 `run_id 填 "B"`。

## 3｜出圖工具：貼上與自動檢查（5 分鐘）

1. 公司設定檔選「NFLX｜Netflix」。
2. A 欄貼 Claude 的 JSON，B 欄貼 ChatGPT 的 JSON（也可以用「選擇檔案」上傳）。
3. 按「檢查」。
4. 看步驟 2：
   - **A 格式錯誤** → 工具會擋住。把錯誤訊息貼回 Claude，請它修正後重新輸出，再貼回來。
   - **B 格式錯誤** → 不擋，B 只用來比對。
   - **勾稽與合理性** → 記下「不通過」與「需確認」各有幾項。

## 4｜人工核對（30–45 分鐘，這次請實際逐項對）

打開 PDF，依步驟 3 三層順序逐項核對：

- **第一層｜基本設定**：8 欄，每一欄都對照 PDF。
- **第二層｜數字**：每一列用 Ctrl＋F 搜尋「列名」，確認那一列、那一欄（看欄名的日期）的數字一致。
- **第三層｜疑慮與差異**：
  - AI 疑慮：判斷 AI 說得對不對。
  - A／B 不同：回原文確認哪一邊對。**圖卡只用 A**；A 錯就修正 A 後回步驟 3 重新檢查。
  - 「不通過」項目：若確認 A 正確，要寫理由才能打勾。

全部打勾後，「產出圖卡」按鈕才會亮起。

**請記下**：花了多久、哪一項最難判斷、有沒有發現 A 的錯誤。

## 5｜圖卡與下載（5 分鐘）

1. 按「產出圖卡」。檢查選圖說明（這次的張次、觸發原因、PN 計算的數字）。
2. 「預告文字」可以改寫；改完按「套用文字」。
3. 切換淺底／深底，選定一種。
4. 按「下載全部 PNG」。下載後**打開檢查字型**：標題應該是襯線字（有筆畫粗細變化的宋體），內文是黑體。如果標題變成黑體，或訊息出現「字型嵌入失敗」，截圖告訴 PN 專案對話。
5. 按「下載本季存檔」，得到 `NFLX_FY2026Q3.json`。上傳方式：在 repo 進入 `history/us/NFLX/` 資料夾，再按 Add file → Upload files 上傳。
