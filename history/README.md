# 歷史存檔與公司繪圖規範

## 公司繪圖規範（chart_rules.json）

每家公司一個：`history/<市場>/<代號>/chart_rules.json`，例如 `history/us/NFLX/chart_rules.json`。在出圖工具第 4 步「繪圖設定」調整後按「下載繪圖規範」，上傳到這個位置（同名覆蓋）。**出圖工具每次會自動讀取**，沒有這個檔案就用通用預設。格式與可調整的項目見 `rules/chart_rules.md`。

## 本季存檔

每次出完圖，在出圖工具第 5 步按「下載本季存檔」，把檔案上傳到 `history/<市場>/<代號>/`，例如 `history/us/NFLX/NFLX_FY2026Q3.json`。資料夾不存在時，上傳畫面的檔名欄可以直接打 `history/us/NFLX/` 建立。

存檔內容：實際用來出圖的數據、AI 原始輸出、人工修改紀錄、第三層每一項的處理結果、數據檢查與繪圖檢查結果、選圖結果、當季套用的繪圖規範。

目前用途是**核對紀錄**（事後可追查每個數字是誰、為什麼改的）。出圖工具還不會讀回本季存檔（會讀的只有 chart_rules.json）；之後接上後，可用於：
- 下一季比對「去年同期」數字是否一致（抓 AI 抓錯欄、公司重編）
- E 卡（對比預期）需要上一季的公司財測
- D 卡的季變動與近 8 季走勢
