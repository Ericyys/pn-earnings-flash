# 歷史存檔與公司規範

## 公司規範（company_rules.json）

每家公司一個：`history/<市場>/<代號>/company_rules.json`，例如 `history/us/NFLX/company_rules.json`。內容是這家公司的算式（EPS 的分子、毛利組成等）、營收拆解的小計與調節項目、科目中文名稱。在出圖工具核對步驟的「公司規範」設定後按「下載公司規範」，上傳到這個位置（同名覆蓋）。**出圖工具每次會自動讀取**，沒有這個檔案就用通用算式。說明見 `rules/company_rules.md`。

## 本季存檔

每次出完圖，在出圖工具第 4 步按「下載本季存檔」，把檔案上傳到 `history/<市場>/<代號>/`，例如 `history/us/NFLX/NFLX_FY2026Q3.json`。資料夾不存在時，上傳畫面的檔名欄可以直接打 `history/us/NFLX/` 建立。

存檔內容：實際用來出圖的數據、AI 原始輸出、人工修改紀錄、第三層每一項的處理結果、自動檢查結果、選圖結果（含資料不完整沒產出的圖卡）、當季套用的公司規範。

目前用途是**核對紀錄**（事後可追查每個數字是誰、為什麼改的）。出圖工具還不會讀回本季存檔（會讀的只有 company_rules.json）；之後接上後，可用於：
- 下一季比對「去年同期」數字是否一致（抓 AI 抓錯欄、公司重編）
- E 卡（對比預期）需要上一季的公司財測
- D 卡的季變動與近 8 季走勢
